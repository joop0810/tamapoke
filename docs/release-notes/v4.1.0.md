# Dennis-Build 4.1.0

Aufbauend auf eperdeme TamaPoke 4.0. Spielstände bleiben erhalten.

- Deutsche Namen für alle Pokémon, Items, Typen, Arenaleiter und Städte
- Alle neun Regionen wählbar; eine Region erscheint, sobald ihre Bilder auf der SD sind
- SD löschen über das Tool
- Erfahrung aus Kämpfen, Fangchance im Beutel, NEU / Pokéball-Markierung, Fangen trägt in den Pokédex ein
- Bälle im Stapel, Top-Genesung, Sonderbonbon, Lockstoff
- Geld und Laden im Beutel (kaufen und zum halben Preis verkaufen)
- Box: Haken für fertige Reihen und Doppelte, AUFRAEUMEN
- Ruhmeshalle mit Sichern/Wiederherstellen im Tool
- Vitrinen-Modus für die Wand
- Robusteres Speichern nach Kämpfen, Speicher-Warnung nur bei echtem Problem
- Behoben: kurzes Schwarzwerden beim Antippen
- Die Fehler-Diagnose aus 4.0.11–4.0.15 ist wieder ausgebaut
